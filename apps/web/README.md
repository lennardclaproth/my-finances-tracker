# Vue + Vite + Tailwind

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The transactions page is available at `/cashflow/transactions`.
During development, API calls are proxied from `/api/*` to `http://localhost:6060/*`.

Optional API base override:

```bash
VITE_API_BASE_URL=/api
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
